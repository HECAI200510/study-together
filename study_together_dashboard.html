让朋友上传到 GitHub

在 GitHub 新建仓库，例如 study-log，建议先设为 Private。
每天完成后点击本页的“导出今日 Markdown”，得到类似 daily/2026-07-30.md 的文件。
进入仓库，点击 Add file → Upload files，把 Markdown、代码作业和少量截图拖进去。
提交信息写清楚，例如 Day 01: Python basics and 2 exercises，然后 Commit。
你负责每周看一次：是否有实际代码、笔记是否具体、计划是否按时完成。不要只数绿色格子。
