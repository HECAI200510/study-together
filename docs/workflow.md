# StudyTogether 学习流程

StudyTogether 使用“计划 → 执行 → 复盘 → 提交 → 回顾”的闭环，让学习过程可以被观察、复用和持续改进。

## 1. 每日计划

开始学习前，用 5 分钟确定当天最重要的 3–5 项任务。

- 每项任务应有明确的完成标准，例如“完成 3 道二叉树题并写出复杂度分析”
- 为任务设置合理的预计时长
- 优先完成当天最重要、最困难的一项任务

## 2. 专注执行

学习过程中在 Dashboard 更新任务状态。记录真实的学习时长，不用“坐在电脑前的时间”代替有效投入。

如果任务过大，应将它拆成一次专注时段内可以完成的小任务。

## 3. 每日复盘

结束学习后完成三个问题：

1. 今天真正学会了什么？
2. 遇到了什么问题，已经尝试过哪些方法？
3. 明天最重要的行动是什么？

点击“导出今日日志”，将文件保存为 `daily/YYYY-MM-DD.md`。

## 4. GitHub 留痕

把学习日志、练习代码和必要的说明提交到 GitHub：

```bash
git add daily/YYYY-MM-DD.md
git commit -m "Day XX: 学习主题"
git push
```

一次 Commit 应对应一组完整、可理解的学习成果。提交信息要说明学了什么或完成了什么。

## 5. 每周回顾

每周固定一次回顾：

- 检查任务完成率和有效学习时间
- 回看 GitHub 提交，确认有真实代码或具体笔记
- 找出本周最常见的卡点
- 调整下周各学习方向的时间分配
- 选择一个可以展示的阶段性成果

## 推荐目录习惯

```text
daily/       每日复盘
notes/       主题笔记
projects/    阶段项目
exercises/   算法与课程练习
```

保持结构简单且长期一致，比短期内设计复杂的分类更重要。
