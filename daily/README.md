# 每日学习日报

每位学习者使用自己的目录保存日报：

```text
daily/
└── learner-name/
    ├── 2026-07-30.md
    ├── 2026-07-31.md
    └── 2026-08-01.md
```

文件名统一使用本地日期 `YYYY-MM-DD.md`，不要使用“今天.md”或“日报最新版.md”等无法长期排序的名称。

网页中的“导出今日 Markdown”会生成正确的文件名。上传时请同时提交当天产生的代码、练习或必要笔记，不能只提交空泛的打卡文字。

日报模板位于 [`templates/daily-template.md`](../templates/daily-template.md)。
